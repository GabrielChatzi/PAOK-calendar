# Εικόνες για τα social

`fixtures.mjs`: το σχέδιο «Πρόγραμμα αγώνων» (σκούρο, λεπτές ρίγες, μέρα με χοντρά στενά γράμματα που
σβήνουν, ημερομηνία καλλιγραφική μισή πάνω στη μέρα). Για κάθε μέρα ένα JSON στο `days/` και:

    node social/fixtures.mjs social/days/2026-11-07.json out/

Βγάζει ποστ 1080×1350 και story 1080×1920. Τα σήματα των αντιπάλων μπαίνουν στο `logos/`
(ή URL στο JSON). Στα τμήματα γράφουμε πάντα «Ανδρών» ή «Γυναικών».

`results.mjs`: τα αποτελέσματα, το ίδιο σχέδιο ανάποδα (ανοιχτό φόντο, μαύρα γράμματα) με το σκορ
δεξιά, γηπεδούχος πρώτα· ο αριθμός του ΠΑΟΚ μαύρος, του αντιπάλου αχνός γκρι. JSON στο `results/`, με "us" και "them" αντί για "time".
